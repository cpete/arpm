# ARPM
This is the repository for the module *ARPM* (*Agile Research Project Management*) in the study programm *Research Master Data Science* at *Hochschule Bielefeld - Campus Gütersloh*.

The repo is for educational purposes only.

## Todo List App

A todo list app built with [Plotly Dash](https://dash.plotly.com/).

### Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

### Run

```bash
python -m todo_app
```

Then open http://127.0.0.1:8050 in your browser.

### Test

```bash
pytest
```
